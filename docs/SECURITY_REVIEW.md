# Security and release review

Reviewed against the implementation in this repository on September 28, 2026. This is an engineering review of an independent synthetic-data prototype, not a security certification, HIPAA assessment, or assurance that the application is fail-proof. It is not affiliated with UT Dallas or the Center for BrainHealth, is not a clinical tool, does not diagnose, and must never receive real patient or research-participant information.

## Transport and external data flow

| Path                                             | Protocol/configured control                                                                                                                                                                                                                                                                                                                                                          | Verification method                                                                                                                                                                            | Result                                                                                      | Remaining risk                                                                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Browser ↔ React/GraphQL/auth/download initiation | Production origins must be HTTPS; `VITE_API_URL` rejects `http:`; same-origin relative requests are default. Server sets CSP, no-referrer, no-store on application/API responses. HSTS is off by default; after verification it requires `ENABLE_HSTS=true` and a host HTTPS signal. Render documents managed TLS and HTTP redirects. Local-only development uses HTTP on localhost. | Unit config tests and `shouldEmitHsts` tests; API header tests; Playwright local HTTP browser tests; inspect `WEB_ORIGIN`, Render config and official host docs. | API ↔ PostgreSQL                                 | Production `DATABASE_URL` requires `sslmode=verify-full`; `pg` uses Node TLS verification; certificate-verification disabling is rejected.                                                                                                                                                                                                                                           | Production config tests; no managed database handshake.                                                                                                                                        | Fail-closed configuration tested. **Connection and at-rest encryption unverified.**         | Exact URL/provider CA chain, network policy, at-rest encryption and backups need an account.                          |
